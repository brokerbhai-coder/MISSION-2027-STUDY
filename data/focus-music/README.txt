यहाँ अपने Focus गाने (mp3, ogg, wav या m4a) डालो।

कैसे जोड़ें:
1. गाने की फ़ाइल का नाम आसान रखो, बिना स्पेस के (जैसे lofi-1.mp3)।
2. इसी folder (data/focus-music/) में GitHub पर "Add file → Upload files" से डालो।
3. manifest.json खोलो और "tracks" की list में एक entry जोड़ो:
   { "file": "data/focus-music/lofi-1.mp3", "title": "Lofi Study 1" }
   एक से ज़्यादा गाने हों तो हर एक की अलग entry, कॉमा से अलग।
4. Commit करो, 1-2 मिनट रुको।

ध्यान रखो:
- गाना अपने-आप बजेगा, लेकिन पहले पेज पर कहीं भी एक बार tap करना ज़रूरी है — यह फ़ोन के browser का अपना नियम है, website इसे बदल नहीं सकती।
- हर फ़ाइल छोटी रखो (लगभग 3-8 MB), ताकि data कम खर्च हो और जल्दी लोड हो।
- सिर्फ़ अपनी ही या copyright-free/royalty-free गाने डालना — यह ज़िम्मेदारी तुम्हारी है।
- एक से ज़्यादा गाने हों तो वे अपने-आप बदल-बदल कर (बिना तुरंत दोहराए) बजते हैं; ऊपर 🔊 panel में "⏭ अगला गाना" बटन से भी बदल सकते हो।
- कोई गाना न मिले या फ़ाइल टूटी हो तो website अपने-आप पुरानी हल्की background आवाज़ पर लौट आती है — कभी टूटती नहीं।
