# AI Prompt — Physics (कक्षा 12, बिहार बोर्ड): सिर्फ़ Notes (100% कवरेज की जाँच + चित्र)

यह prompt सिर्फ़ **Notes** बनवाता है (प्रश्न-संग्रह / MCQ नहीं)। हर Chapter के Notes तुम्हारी website के **असली format** में आते हैं। Template prompt के अंदर ही लिखा है, अलग से कुछ attach नहीं करना।

## इस्तेमाल का तरीका (सिर्फ़ 3 कदम)

1. ऐसा AI tool खोलो जो बड़ी फ़ाइलें/PDF पढ़ सके। **हर Chapter के लिए नई chat** खोलो। उसमें अपनी **किताब** और **अपने notes** (उस Chapter के) attach करो।
2. नीचे के `~~~~` के बीच का पूरा prompt कॉपी करके paste करो। सिर्फ़ पहली पंक्ति के `[ ]` में Chapter की संख्या और नाम भरो।
3. AI पहले **Chapter Map** देगा। उसे अपनी किताब से मिलाकर देखो और "ठीक है" लिखो। फिर वह **हर बार एक फ़ाइल** देगा। उसे jsonlint.com पर जाँचो, GitHub पर उसके बताए नाम से सेव करो, manifest में उसकी बताई पंक्ति जोड़ो, और AI को **"अगला"** लिखो।

**बीच में काम आने वाले संदेश:** "अगला" · "ठीक है, भाग 1 दो" · "यह JSON अधूरा था, यही फ़ाइल पूरी दोबारा दो" · "इस भाग में ये बिंदु छूटे हैं: … इन्हें जोड़कर दो"

**Physics के Chapters (तुम्हारी `subjects.json` से):** 1 वैद्युत आवेश तथा क्षेत्र · 2 स्थिरवैद्युत विभव तथा धारिता · 3 वैद्युत धारा · 4 गतिमान आवेश एवं चुम्बकत्व · 5 चुम्बकत्व एवं द्रव्य · 6 वैद्युत चुम्बकीय प्रेरण · 7 प्रत्यावर्ती धारा · 8 वैद्युत चुम्बकीय तरंगें

## PROMPT (यहाँ से कॉपी करो)

~~~~
इस बार का Chapter: [यहाँ भरो, जैसे: अध्याय 1 — वैद्युत आवेश तथा क्षेत्र]

तुम कक्षा 12 (बिहार बोर्ड) भौतिकी के अनुभवी शिक्षक और सावधान JSON-लेखक हो। मेरी study website के लिए, ऊपर लिखे Chapter के **सिर्फ़ Notes** बनाने हैं (MCQ या Practice प्रश्न-संग्रह नहीं बनाना)। मैंने अपनी किताब और अपने notes attach किए हैं।

## A. स्रोत के नियम (सबसे ज़रूरी)
1. सामग्री का आधार सिर्फ़ मेरी attach की हुई किताब और मेरे notes (इसी Chapter का भाग) हैं। syllabus से बाहर की बात अपनी तरफ़ से मत जोड़ो।
2. किताब और notes में अंतर हो तो किताब मानो, और अंतर अंत की रिपोर्ट में लिखो।
3. जो बात किताब/notes में साफ़ न हो, उसे अनुमान से मत लिखो। उसे रिपोर्ट के "जाँचने लायक" हिस्से में डालो।
4. किताब की लाइनें हूबहू मत उतारो। सरल हिंदी में अपने शब्दों में लिखो, पर अर्थ, सूत्र, संख्याएँ और इकाइयाँ (मात्रक) बिल्कुल वही रखो।
5. भाषा: सरल हिंदी (देवनागरी); तकनीकी शब्द वही जो किताब में हैं। सूत्र सादे text में Unicode से लिखो, जैसे F = k q₁q₂ / r², ε₀, ∮, →, ×, ≈, θ, Ω। LaTeX या $ चिह्न बिल्कुल नहीं।

## B. काम का क्रम (हर चरण के बाद रुको; मैं "अगला" या "ठीक है" लिखूँगा)

### चरण 0 — Chapter Map (सिर्फ़ text, JSON नहीं)
Chapter के सारे शीर्षक और उपशीर्षक क्रम से लिखो। हर एक के सामने लिखो: कितने सूत्र, कितने चित्र/graph/परिपथ, कौन-सी परिभाषाएँ, कौन-से नियम/प्रमेय, कौन-सी व्युत्पत्तियाँ (derivation)। अंत में कुल गिनती दो। मैं इसे किताब से मिलाकर "ठीक है" लिखूँगा।

### चरण 1 — Notes (4 भाग, हर भाग एक अलग JSON फ़ाइल)
- भाग 1: chapterNotes + theory
- भाग 2: definitions + formulas + oneLiners
- भाग 3: shortAnswers + longAnswers
- भाग 4: diagrams + revision
कोई भाग बहुत बड़ा हो जाए तो उसे खुद ही भाग 1अ, 1ब … में बाँट दो। कभी अधूरा JSON मत दो।

**100% कवरेज:** Chapter Map का हर बिंदु किसी न किसी भाग में आना चाहिए। कुछ भी न छूटे। हर व्युत्पत्ति पूरी, कदम-दर-कदम (theory और longAnswers में) लिखो। हर सूत्र में चिह्नों का अर्थ और मात्रक लिखो।

**लक्ष्य (किताब में जितना सचमुच मिले उतना, बढ़ाने के लिए गढ़ना नहीं):**
- definitions: किताब की हर परिभाषा (कम से कम 15)
- formulas: Chapter का हर सूत्र, मात्रक और चिह्नों के अर्थ के साथ
- oneLiners: कम से कम 40 (एक पंक्ति का प्रश्न, छोटा उत्तर; सब किताब से)
- shortAnswers: कम से कम 15; longAnswers: कम से कम 6 (व्युत्पत्तियाँ और बोर्ड में पूछे जाने लायक)
- revision: सूत्र-सारणी और याद रखने वाले बिंदु
अगर किताब में लक्ष्य से कम सामग्री है तो उतनी ही रखो और रिपोर्ट में बताओ।

**Game के लिए ज़रूरी:** definitions, formulas और oneLiners के उत्तर **छोटे और एक-दूसरे से अलग** हों। दो प्रश्नों का एक ही उत्तर न हो (Game के गलत विकल्प इन्हीं से बनते हैं)।

**Diagrams (भाग 4):** Chapter Map के हर महत्वपूर्ण चित्र, graph, परिपथ और किरण-आरेख को inline SVG में बनाओ। SVG के नियम:
- "svg" की कीमत `<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 400 260'>` से शुरू हो
- attributes में सिर्फ़ **एकल कोट '** इस्तेमाल करो (दोहरा कोट " नहीं, ताकि JSON न टूटे)
- गहरे रंग की रेखाएँ (जैसे stroke='#222'); पृष्ठभूमि सफ़ेद मानी जाएगी; text के लिए font-family='sans-serif' font-size='13'
- सिर्फ़ line, path, circle, rect, polygon, text और marker (तीर के लिए) इस्तेमाल करो; कोई script, style, बाहरी image या link नहीं
- text में < > & न लिखो (लिखना ज़रूरी हो तो &lt; &gt; &amp;)
- हर लेबल छोटा हो (जैसे +q, E, B, θ, R); हर SVG 6000 अक्षरों से छोटा हो
- हर चित्र का "caption" लिखो जो चित्र समझाए
जो चित्र SVG में सही नहीं बन सकता (जैसे फ़ोटो जैसा जटिल), उसे diagrams में मत डालो। रिपोर्ट के "छूटे चित्र" में उसका नाम और वर्णन लिखो।

**Notes फ़ाइल का format (हर भाग यही ढाँचा; जिस category का काम इस भाग में नहीं, उसे हटा दो):**
```json
{
  "schemaVersion": 1,
  "subject": "physics",
  "chapter": 1,
  "title": "Chapter का नाम",
  "categories": {
    "chapterNotes": [ { "heading": "शीर्षक", "content": ["अनुच्छेद 1", "अनुच्छेद 2"], "points": ["बिंदु 1", "बिंदु 2"] } ],
    "theory": [ { "title": "Topic का नाम", "content": ["व्याख्या"], "points": ["बिंदु"] } ],
    "oneLiners": [ { "question": "एक पंक्ति का प्रश्न?", "answer": "छोटा उत्तर" } ],
    "shortAnswers": [ { "question": "लघु प्रश्न?", "answer": ["उत्तर का भाग 1", "भाग 2"] } ],
    "longAnswers": [ { "question": "दीर्घ प्रश्न?", "answer": ["चरण 1", "चरण 2", "चरण 3"] } ],
    "definitions": [ { "term": "शब्द", "definition": "परिभाषा" } ],
    "formulas": [ { "name": "सूत्र का नाम", "formula": "F = k q₁q₂ / r²", "meaning": "चिह्नों का अर्थ", "unit": "मात्रक" } ],
    "diagrams": [ { "title": "चित्र का नाम", "svg": "<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 400 260'>…</svg>", "caption": "चित्र क्या दिखाता है" } ],
    "revision": [ { "title": "शीर्षक", "points": ["बिंदु 1", "बिंदु 2"] } ]
  }
}
```
- फ़ाइल का नाम: `data/notes/physics/chapter-XX-part-N.json` (XX = दो अंक का अध्याय, जैसे 01; N = भाग)
- manifest में जोड़ने की पंक्ति (हर फ़ाइल के साथ यह भी दो):
`{ "subject": "physics", "chapter": 1, "part": "N", "file": "data/notes/physics/chapter-01-part-N.json" }`

### चरण 2 — अंतिम रिपोर्ट (सादा text, JSON नहीं)
(क) Chapter Map के कितने बिंदु कवर हुए, और किस भाग में (सूची सहित)
(ख) जो बिंदु छूटे या अधूरे रहे
(ग) "जाँचने लायक" बातें: जहाँ किताब और notes में अंतर था, या तुम्हें पक्का भरोसा नहीं था
(घ) "छूटे चित्र": जो चित्र SVG में नहीं बन सके
(ङ) सारी manifest पंक्तियाँ एक साथ, कॉपी करने लायक

## C. हर उत्तर का आउटपुट नियम
1. हर उत्तर में **सिर्फ़ एक फ़ाइल**: पहली पंक्ति "फ़ाइल का नाम: …", फिर **एक ही ```json code block**, फिर "manifest में जोड़ो: …" की पंक्ति, और आख़िर में "फ़ाइल पूरी ✅"। इसके बाहर कोई और लंबी बात नहीं।
2. JSON बिल्कुल सही हो: text के अंदर " आए तो \" लिखो; नई पंक्ति के लिए \n; आख़िरी आइटम के बाद कॉमा नहीं; कोई टिप्पणी (comment) नहीं; Unicode अक्षर सीधे लिखो (\u… नहीं)।
3. भेजने से पहले खुद जाँचो: JSON खुलता है, हर आइटम में ज़रूरी खाने भरे हैं, SVG के tag बंद हैं, कोई परिभाषा/उत्तर दोहराया नहीं गया।
4. जवाब बीच में कटने का डर हो तो फ़ाइल को छोटे भागों में बाँटो। अधूरा JSON मत दो।
5. चरण 0 का Chapter Map अभी दो, और मेरे "ठीक है" का इंतज़ार करो।
~~~~
